# 📱 Smartphone Usage Analysis

## 📌 Project Overview
This project analyzes smartphone usage patterns to understand user behavior, screen time, app usage, and other usage-related trends.

The project uses Python and data analysis libraries to clean, explore, visualize, and derive meaningful insights from smartphone usage data.

## 🎯 Objectives
- Analyze overall smartphone usage patterns
- Identify frequently used applications
- Analyze screen time and usage duration
- Identify trends and patterns in user behavior
- Generate meaningful insights from the dataset

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Data Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Descriptive statistics
- App usage analysis
- Screen-time analysis
- Data visualization
- Business-style insight generation

## 📈 Visualizations
The project includes visualizations such as:
- App usage comparison
- Screen time analysis
- Usage distribution
- Category-wise usage
- Correlation analysis

## 🔍 Key Insights
- Identified applications with the highest usage.
- Compared smartphone usage across different categories.
- Analyzed patterns in screen time and user activity.
- Identified factors associated with higher smartphone usage.
